# 05 — Skill Explanation layer

**What to build:** A one-sentence, LLM-generated justification per scored skill, produced lazily and cached, with a deterministic fallback so the Evidence Card is never left confusing when the LLM is unavailable.

**Blocked by:** 04 (needs a scored Evidence Card to explain).

**Status:** done

- [x] `POST /explain/{candidate_id}/{skill}` operates against an existing Evidence Card for that candidate + Skill Tag.
- [x] The explanation is generated by Groq (Llama 3.3 70B, free tier) from the same qualifying Evidence Items already used in scoring for that skill.
- [x] A successfully generated explanation is cached on the Evidence Card; a repeat call/view does not re-trigger the LLM.
- [x] If the Groq call fails or is rate-limited, a deterministic template sentence built from evidence stats (commit count, repo count, day span) is returned/stored instead, and the real explanation is generated transparently on a later successful call.

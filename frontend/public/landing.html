how it works

Three steps, zero self-assessment

A Candidate connects GitHub once, claims the skills they want checked, and gets back a scored, sourced record instead of a resume adjective.

01

Connect GitHub

One OAuth redirect, read-only public scope. Your token stays encrypted; re-verifying later is a single click.

02

Claim Skill Tags

Pick from a curated taxonomy by autocomplete — up to 8 per pass. No free text, so there's nothing to embellish.

ReactPostgreSQLDockerRust
03

Get Evidence Cards

SkillProof scans manifests, commits, and PR comments in the background and scores each claim while you wait.

confidence score

One score, four signals, no vibes

The Confidence Score is a fixed weighted sum — never a single similarity average. Two deterministic signals anchor it; embeddings are used only where natural language actually compares well against natural language.

Presence 20% Volume 40% Depth 25% Span 15%
Presence 20%
A Detection Pattern match in a manifest or file extension — deterministic, no scan of code content.
Volume 40%
Count of the Candidate's own commits touching matched files, PR-verified on repos they don't own.
Depth 25%
Embedding similarity of top-3 commit messages and PR comments against the skill's canonical description.
Span 15%
A saturating curve over the date range of the full qualifying evidence set — sustained use, not a weekend.

what's next

Not everything worth proving has a commit history

Some claims — system design judgment, a private internship, a specific decision inside one commit — can't be read off a manifest. That's what the Depth Interview is for.

In design — not yet built

Depth Interview

An unscored, LLM-conducted conversation for skills with no code footprint to check. It doesn't produce a Confidence Score — it produces a transcript, attached to your Evidence Card as supporting context a Recruiter can actually read.

Code-anchored

The interviewer opens one of your real commits and asks you to walk through the decision behind it — live, in your own words.

Experience-anchored

For work that never touched a public repo — a private codebase, an internship — probing your own account of it directly.
